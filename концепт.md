# Концепция проекта «Планировщик задач»

## Идея

Личный веб-планировщик для спокойного и наглядного планирования дел на день, неделю и месяц. Главный экран — календарь-сетка: он помогает увидеть занятое время и выбрать подходящий день и временной интервал для новой задачи.

## Для кого

Для одного пользователя, который планирует собственные дела. Основной сценарий использования — на компьютере; интерфейс также стоит адаптировать для телефона и планшета.

## Представления календаря

- **День:** подробная сетка времени для выбранной даты.
- **Неделя:** расписание по дням недели с временными интервалами.
- **Месяц:** календарная сетка месяца с расположением задач по датам.

Переключение между представлениями должно быть доступно из календаря. Пользователь может выбрать дату и время при создании задачи.

## Задачи

У задачи есть название, дата, время, приоритет, заметка и статус. Категории не используются. Заметка — отдельное необязательное поле для дополнительной информации.

Статусы задачи:

- выполнено;
- в процессе;
- отложено;
- перенесено.

Задачу можно переместить на другое время того же дня или на другой день. После переноса её дата и время обновляются, а статус можно отметить как «перенесено».

Повторяющиеся задачи и напоминания не входят в проект.

## Сохранение

Задачи должны оставаться доступными после закрытия и повторного открытия страницы. Для первой версии данные можно сохранять локально в браузере на устройстве пользователя. Это не синхронизирует задачи между разными устройствами или браузерами.

## Визуальный стиль

Минималистичный, спокойный, строгий и уютный. Ориентир по компоновке — приложенный пример календаря: слева панель переключения между днём, неделей и месяцем, сверху заголовок периода с кнопками перехода и «Сегодня», справа основная область календаря. В недельном виде дни расположены по колонкам, время — по строкам; задачи показаны блоками с названием и временем. Часовые строки имеют тонкие деления для выбора времени с шагом 15 минут. Использовать свободное пространство, аккуратные линии сетки, читаемые подписи и мягкие оттенки задач в согласованной бежево-голубой палитре.

## Первая версия

1. Переключение между календарями дня, недели и месяца.
2. Создание, просмотр, изменение и удаление задачи.
3. Выбор даты и времени в календарной сетке.
4. Изменение приоритета и статуса.
5. Перенос задачи на другое время или дату.
6. Сохранение задач в браузере между сеансами.
7. Адаптация календаря для компьютера и небольших экранов.

## Формат реализации

Веб-страница будет состоять из трёх файлов: HTML, CSS и JavaScript. Этот документ фиксирует концепцию; код страницы на данном этапе не создаётся.
